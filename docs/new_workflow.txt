# 🎯 DDoS Detection System - How It Works

## **The Big Picture**

You have a **Production DDoS Detection System** that:
1. **Detects** DDoS attacks in real-time (inference)
2. **Stays resilient** - Never crashes under attack
3. **Privacy-preserving** - Built with federated learning (model already trained)
4. **Production-ready** - Deployed as Docker container or local API

---

## **How It Works**

### **Foundation: Pre-trained Model**

The system uses a **pre-trained CNN model** built with federated learning:
- Trained on 65,000 real DDoS samples across 4 distributed networks
- Each network trained locally (data never shared) → Server aggregates safely with Multi-Krum
- Final model: **76.99% accuracy, 85.10% ROC-AUC**
- Model file: `results/ddos_model.h5`

---

### **Real-Time Detection Pipeline**

```
Live Network Traffic
    ↓
Extract 30 Features (packet metadata)
    ↓
API Service (REST endpoint)
    ↓
Pass to Pre-trained CNN Model
    ↓
Model Predicts: "Benign" or "Attack" + Confidence
    ↓
Return Result (45ms latency)
```

**Result:** Detects DDoS attacks in real-time ✅

## **How to Demonstrate Detection - 3 Methods**

### **Method 1: Single Threat Detection**

**Send one network packet for analysis:**
```powershell
curl -X POST http://localhost:5000/predict `
  -H "Content-Type: application/json" `
  -d '{
    "features": [0.5, 1.2, 0.3, 2.1, 0.8, 0.2, 1.5, 0.9, 0.4, 1.1, 0.6, 0.3, 2.0, 0.7, 1.3, 0.8, 0.5, 0.9, 1.2, 0.4, 0.7, 1.0, 0.6, 0.3, 1.5, 0.8, 0.4, 1.1, 0.9, 0.2],
    "model": "standard"
  }'
```

**Response:**
```json
{
  "prediction": "Attack",
  "confidence": 0.92,
  "risk_score": 0.92,
  "processing_time_ms": 43.2
}
```

✅ **Shows:** This is a DDoS attack with 92% confidence

---

### **Method 2: Bulk Analysis (100 packets)**

**Send many packets at once:**
```powershell
python -c "
import requests
import json
import numpy as np

# Simulate 100 network samples (30 features each)
samples = [{'features': np.random.rand(30).tolist()} for _ in range(100)]

response = requests.post('http://localhost:5000/batch',
  json={'samples': samples, 'model': 'standard'})

result = response.json()
print(f'Attacks detected: {result[\"attacks_detected\"]}/100')
print(f'Detection rate: {result[\"attack_percentage\"]:.1f}%')
"
```

**Response:**
```json
{
  "total_samples": 100,
  "attacks_detected": 47,
  "benign_detected": 53,
  "attack_percentage": 47.0,
  "average_confidence": 0.8432,
  "processing_time_ms": 2847
}
```

✅ **Shows:** 47 out of 100 packets identified as DDoS attacks

```powershell
python client.py --cid 3 --epochs 5
```

This shows privacy-preserving training where:
- Each network trains independently
- Models sent to server (NOT raw data)
- Server combines models safely (Multi-Krum)
- Global model broadcast back to all
